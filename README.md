# 🧠 Guess Me

> **Limited Questions. Unlimited Thinking.**

**Guess Me** is a simple word-guessing game built with **HTML, CSS, and JavaScript**. Read the clue, guess the word, and test your vocabulary across different difficulty levels.

## 🎮 Features

* 🟢 Easy, 🟡 Medium & 🔴 Hard difficulty
* 💯 Score-based gameplay
* 💡 Hint system
* 📊 Progress tracking
* 🔀 Randomized questions
* 📱 Responsive design
* 🔄 Replayable rounds

## 🛠️ Built With

* **HTML5**
* **CSS3**
* **JavaScript**

## 📌 Future Ideas

* 🏆 High-score system
